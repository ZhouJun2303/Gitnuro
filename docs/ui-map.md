# 界面代号

跟 AI 说位置时用这张表。代号对上之后再改对应文件。

## 写法

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `A` | 整个界面 | `A` 欢迎页 |
| `B3` | 该界面里的一块区域。数字从上到下、从左到右 | `B3` 变更文件列 |
| `B3-1` | 区域里的更小一块 | `B3-1` 未暂存列表 |
| `Com2` | 多处复用的同一块，不单独占一个界面字母 | `Com2` 侧栏 |
| `Com2-5` | 复用模块内部 | `Com2-5` 本地分支 |
| `B4 Com3` | 先说界面区域，再说它用的复用模块。两者是同一块 | 本地更改右侧的差异窗格 |
| `E:pull` | 某一种操作对话框。冒号后是 `shell.dialog` 的值 | 拉取对话框 |
| `D3:git` | 偏好设置里的某一页 | Git 设置页 |

规则：

- 已分配的字母和数字不重排。新界面用下一个空字母，新区域用该界面下一个数字。
- 删掉的区域不要把后面的号码前移，在表里标「停用」。
- 同一块出现在两个以上界面，用 `Com`，不要在每个界面各编一个互不相干的号。
- `D`、`E`、`F`、`G` 盖在当前主界面上面，底下仍是 `A`、`B` 或 `C`。
- 垂直标签只改变 `Com1-5` 的位置（贴到窗口左侧），代号不变。
- 已暂存显示在未暂存上面时，只是 `B3-1` 和 `B3-2` 交换上下位置，代号仍按「未暂存 / 已暂存」理解。

| 代号 | 界面 | 什么时候出现 | 文件 |

主界面都包在 `src/lib/Shell.svelte` 里。`A`、`B`、`C` 上方都有顶栏。

```
A 欢迎
┌ Com1 顶栏 ─────────────────────────┐
│ A2 品牌                             │
│ A3 打开 / 克隆 / 新建               │
│ A4 最近仓库                         │
└─────────────────────────────────────┘

B 本地更改                         C 全部提交
┌ Com1 顶栏 ────────────────────┐  ┌ Com1 顶栏 ────────────────────┐
│ Com2 │ B3 文件列 │ B4 差异     │  │ Com2 │ C3 提交列表            │
│ 侧栏 │          │ B5 提交框   │  │ 侧栏 │ C4 提交详情            │

```
