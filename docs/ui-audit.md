检查对象是当前有效试验台场景及合并独立窗口。保留 `pnpm dev` 的 1420 试验台入口，删除没有正式调用方的旧 `resolve` 对话框、对应样式和场景；Git 的 `resolve` 写操作保留。

## 已修复

| 问题 | 当前行为 |
| --- | --- |
| 合并先打开遮罩面板，不能持久保存原生位置 | 直接使用一个可移动、缩放的原生窗口，单独保存位置、宽高和最大化状态 |
| 重复打开和切换可能覆盖未应用内容 | 同文件保留草稿；切换文件或仓库、关闭窗口时提示确认 |
| 解决失败仍关闭面板 | 文本和二进制失败均保留选择、草稿和窗口，显示错误并允许重试 |
| 手工编辑后的预览仍显示旧选择 | 预览显示实际草稿，改选一侧前保护手工修改 |
| 选择空版本仍把占位符写入结果 | 空版本按删除处理，保留前后公共内容，不写占位符或额外空行 |
| 只能悬停后操作冲突块 | 每块选择按钮支持键盘聚焦，危险确认默认聚焦取消 |
| 选择后结果区定位偏移、两侧滚动可能互相回写 | 等待新布局再定位，按实际目标位置识别同步滚动，每帧最多更新一次 |
| 大文件最后仍把全部内容放进 DOM | 按块虚拟渲染，包括单个巨大冲突、长公共上下文和手工预览 |
| 小窗口底部操作挤压、冲突提示不清楚 | 标题和操作区固定，提示和按钮允许换行；未选冲突提示下一步操作，保存错误使用主题适配的文字和背景色 |
| 批量冲突测试修改共享仓库后不恢复 | 用例结束后恢复冲突试验仓库 |
| 过时的场景入口、固定等待和单个全量大用例 | 每场景独立报告，使用就绪条件；流程偏好场景指向当前高级页 |
